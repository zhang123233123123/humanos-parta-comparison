# Part A 内部比较工具任务规格

状态：已实现并部署至线上 /part-a，本地服务已停止；部署验收未调用模型。2026-11-25。用户已要求实现前后端，采用现有 AgentSociety 接口。

## 目标与范围

研究者选择一份学习任务、一份历史 Profile、难度表达方式（三选一），生成四条件的单日候选计划；预览并核对每次实际请求的完整提示词，查看计划和原系统时间校验结果，保存生成过程。不是正式参与者实验评分页，不发布为当前用户真实日程。

入口 `/part-a` 独立于正式 Workspace。应用代码只在 webapp 内；素材仍从用户已指定的 PartA预实验目录读取。不得把原始数据库、登录身份或模型密钥返回浏览器。

## 已核实现状

- 生产 Next.js 代理现有登录身份；Python ThreadingHTTPServer 使用模块路由 registry。
- `app/domain/simulation/planning.py` 的 `free_windows` 和 `validate_blocks` 是既有日期型可用时间、固定事项、冲突、截止、超额工作量校验。
- 当前主排程器 `ai_ordered_scheduler.py` 由 AI 排顺序、Python 放置具体时间，不能直接作为本次四条件生成器。
- 模型传输 `infrastructure/json_chat.py` 使用 DEEPSEEK_* 配置，支持现有 AgentSociety OpenAI-compatible 网关。
- 历史 Profile 导出原本剔除了旧可用时间，需只读补提取首次设置首日上下文。

## 行为规则

1. 以 Profile 第一阶段首次提交的 `setup_start` 当天为唯一排程日，使用该日可用窗口与固定事项。场景任务的钟点截止与最早开始锚定到该日期；原场景保留的午休／固定休息也作为共同不可用时间。页面明示场景宽松／紧张原始标签不再保证相同约束强度，因为个人可用时间替换了原窗口。
2. 四条件共同任务与时间上下文完全相同。AI-native 只有通用学习规划指令和共同结构输出约定；后三条件共用单日规划 prompt。difficulty 只进入③④，工作方式 Profile 只进入④。历史每日状态、评分、记忆与任务不进入。
3. 难度任选等级 high/medium/low、0–100 整数、1–500 字主观描述。所有任务必填，不自动换算、不推断。每次比较可在页面调整预计时长；只改当前输入副本，不覆盖素材文件。
4. Profile 输入明确采用旧字段：典型精力、专注分钟、休息分钟、任务切换、补充偏好。缺失值保留；不宣称新版五维已完整采集。时间约束来自该人的首日但四条件共享，Profile 软偏好不作为④独有硬校验。
5. 时间硬校验复用原有 `validate_blocks`，外加任务总时长必须足额、当天范围、整分钟、最小工作块、不可拆分约束、依赖校验。统一 cap=1440/rest=0：具体工作块和个性休息为软偏好；场景固定休息为共同硬约束。
6. 四条件使用同一模型、temperature=0.2、相同最大3次生成（初次+最多2次问题修正）；API故障不偷偷切换模型，失败显示错误。保留首次输出及全部尝试。AI-native 标为“通用指令＋共同时间质检”，区别于完全不校验的通用LLM；这是内部比较政策，正式论文条件需据此确认。
7. 预览展示最终 messages 及请求参数，不含 Authorization。运行核对预览哈希防止数据／配置变化；每次尝试同时保存真正送到传输层的请求体与原始模型内容，不能仅展示模板。
8. 生成使用异步任务，刷新可恢复查看；每条件独立成功或失败。重启时未完成记录标为 interrupted，不自动消耗API重跑。失败计划不能标为有效，不采用mock成功回退。

## 页面／API 映射

所有浏览器请求经 `/api/part-a/*` 同源代理，沿用 NextAuth 用户ID，以带时效HMAC签名传后端；后端启用开关＋研究者白名单校验。运行记录隔离于独立SQLite，不改真实任务／Profile。

|方法与路径|输入|返回|持久化|
|---|---|---|---|
|GET /api/part-a/catalog|无|任务素材、历史画像及首日时间、模型公开信息|否|
|POST /api/part-a/preview|scenario_id, profile_id, difficulty_mode, difficulties, duration_overrides|四份messages、共同约束、预检、preview_hash|否|
|POST /api/part-a/runs|同预览输入＋preview_hash＋request_id|202 run|保存输入快照、启动异步生成|
|GET /api/part-a/runs|无|当前研究者最近运行摘要|否|
|GET /api/part-a/runs/{id}|记录ID|完整条件结果、尝试和校验|否|

输入校验400；身份401；权限403；源或模型未配置503；预览过期409。加载、无素材、无首日窗口、不可行预检、调用失败、部分完成、刷新恢复分别显示。重复 request_id 返回同一记录。
