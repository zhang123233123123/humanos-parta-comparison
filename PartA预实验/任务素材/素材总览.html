8 份原文配置摘录 · 3 组学习内容 · 6 份单日候选场景

原文摘录是活动类别、时长范围和学生模板；下方六份具体任务表为研究者改编，尚未预试，不是原数据集的六条真实记录。

抽取的原始素材

这是同一框架中的不同配置片段，不能当作八个独立学习样本。人物覆盖参数与活动目录的通用参数需一起阅读。

E01 · 通用示例：学习活动目录

包含 lecture、self-study 等标签；单次 1–8 小时是该示例的生成范围，不是教学建议。

查看固定版本原文与行号
  education:
    events:
      study:
        human_activity_iri: https://w3id.org/calendar-bench/human-activities/activity/sitting-studying-general-including-reading-and-or-writing-light-effort
        requires:
          occupation_status: { in: [student] }
        weekdays: [Mon, Tue, Wed, Thu, Fri]
        intensity: 2
        is_concurrent: true
        is_dividable: true
        per_event_duration: { min: 1, max: 8, unit: hours }
        total_event_duration: { scale: day, min: 0, max: 8, unit: hours }
        total_event_episodes: { scale: day, min: 0, max: 3 }
        calendar_variations:
          task_labels: [lecture, self-study, work lecture, instructions]
E02 · 学生实验：学习活动目录

包括 lecture、course、self-study、exam、quiz 等日历标签；单次通用范围 1–3 小时。标签不等于独立题本。

查看固定版本原文与行号
      studying:
        human_activity_iri: https://w3id.org/calendar-bench/human-activities/activity/sitting-studying-general-including-reading-and-or-writing-light-effort
        requires:
          occupation_status: { in: [student] }
        weekdays: [Mon, Tue, Wed, Thu, Fri]
        intensity: 2
        is_concurrent: false
        is_dividable: true
        concurrent_with:
          [drink_water, short_movement_break, journaling, napping, snacking]
        per_event_duration: { min: 1, max: 3, unit: hours }
        total_event_duration: { scale: day, min: 1, max: 9, unit: hours }
        total_event_episodes: { scale: day, min: 1, max: 3 }
        calendar_variations:
          task_labels:
            [
              lecture,
              course,
              self-study,
              work lecture,
              instructions,
              exam,
              quiz,
            ]
        temporal_patterns:
          - { mode: fix, details: { within: [morning, afternoon, evening] } }

E04 · 学生模板：学习阶段

模板将学习活动关联到工作日 10:00；这是合成人物设定，不是参与者实测偏好。

查看固定版本原文与行号
  - name: studying
    time: "10:00"
    days: [Mon, Tue, Wed, Thu, Fri]
    human_activity_iri: https://w3id.org/calendar-bench/human-activities/activity/sitting-studying-general-including-reading-and-or-writing-light-effort
E05 · 学生模板：学习时长覆盖

人物覆盖配置：单次 120–240 分钟，每日总量 240–420 分钟，2–3 段；不能只引用 E02 忽略覆盖。

查看固定版本原文与行号
    studying:
      per_event_duration: {min: 120, max: 240, unit: minutes}
      total_event_duration: {scale: day, min: 240, max: 420, unit: minutes}
      total_event_episodes: {scale: day, min: 2, max: 3}
      temporal_patterns:
      - {mode: fix, details: {within: [morning, afternoon]}}
E06 · 学生模板：阅读时长覆盖

人物覆盖配置：单次 60–150 分钟，每日总量 120–240 分钟，1–2 段；这些合成参数未在我们的学生群体中验证。

查看固定版本原文与行号
    study_reading:
      per_event_duration: {min: 60, max: 150, unit: minutes}
      total_event_duration: {scale: day, min: 120, max: 240, unit: minutes}
      total_event_episodes: {scale: day, min: 1, max: 2}
      temporal_patterns:
      - {mode: fix, details: {within: [morning, afternoon]}}
E07 · 环境：时间段定义

定义早晨、下午等时间段，以及场景任务的起止范围；不是特定学生的空闲时间。

查看固定版本原文与行号
time_windows: # named [start, end] ranges, in minutes from midnight
  early_morning: [240, 390] # 04:00 - 06:30
  morning: [390, 720] # 06:30 - 12:00
  afternoon: [720, 1050] # 12:00 - 17:30
  evening: [1050, 1290] # 17:30 - 21:30
  night: [1290, 1440] # 21:30 - 24:00
daily_window: # waking time bracket for scenario-task placement
  wake_minutes: 360 # 06:00
  sleep_minutes: 1320 # 22:00

六份候选场景

建议先选 S1 的一对。S2、S3 是备选内容；每组任务工作量相同，仅配对的可用时间和部分截止时间改变。

S1-L · 课程学习日 · 宽松

围绕一门自己熟悉的课程安排当天学习；各项材料独立提供，没有前后依赖。

可用时间：09:00–12:00、13:00–17:00。
固定休息：10:30–10:45、14:00–14:15；午休 12:00–13:00。

任务 240 分钟 / 净可用 390 分钟 / 余量 150 分钟

任务内容与交付物分钟优先级最早开始截止
阅读课程章节阅读指定章节，记录 5 个关键概念及简短解释。45中09:0017:00
完成课程练习完成一组已学内容的练习题，并标记尚不确定的题目。60高09:0017:00
观看课程录像观看一段可暂停的课程录像，记录 3 个不理解的问题。45中09:0017:00
撰写短作业依据单独提供的材料撰写约 500 字课程分析。60高09:0017:00
整理复习卡片将之前已学的概念整理成 10 张问答卡片。30低09:0017:00
  • 仅在可用时间内排程；固定休息和午休不可安排任务；截止表示必须完成的最晚时间。
  • 五项均需完成；优先级用于冲突取舍，不代表必须按高到低排序。
  • 预计用时包括所列交付物；本轮先作为排程评价材料，并未要求实际完成所有学习内容。
  • 每项可拆分，最小工作块 15 分钟；一次只安排一项任务；无跨任务先后依赖。
  • 参与者报告感知难度及 Profile；不预填个人状态、不预设最优顺序。
  • 录像可暂停；模拟题组是自练任务，非不可移动的正式考试。
